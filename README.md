# paudelbipin.com.np

Personal portfolio of Bipin Paudel, AI & Backend Developer from Bharatpur, Nepal.

Built with Next.js (App Router), TypeScript, and Tailwind CSS. All site content lives in `src/data/portfolio.ts`.

## Development

```bash
npm install
npm run dev
```

## Deploy

Deployed on Vercel. Pushes to `main` go live automatically.
